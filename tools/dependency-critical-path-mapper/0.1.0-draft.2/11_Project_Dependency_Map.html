1. Supply a fictional task network

WORK IN PROGRESS / OFFLINE / SYNTHETIC INPUT ONLY. No network, storage, AI execution, calendar modification, invoice or customer contact. Task dependencies are unverified self-reports. This computes a simple precedence-based critical path from full estimated task durations, not a delivery promise, business-day calendar, staffing schedule or independent verification of completed work.

Header: task_id,title,duration_days,depends_on,status,owner_ref,source_ref,rights. Dependencies are semicolon-separated task IDs or NONE. Duration 1–180 whole days. Status PLANNED, IN_PROGRESS, BLOCKED or REPORTED_DONE. Rights: CLEARED, REVIEW, RESTRICTED; these labels are user assertions, not actual legal approvals. No customer names, emails, financial data, security details or confidential task descriptions. Max 100 KiB CSV and 500 characters per cell.

Planning limits: Zero float means critical under stated estimates and precedence assumptions, not urgent work authorization. REPORTED_DONE is only the user's claim, not evidence of acceptance. Ready means prerequisite states are reportedly done and the input rights label says CLEARED, not that a client authorized execution. BLOCKED/REVIEW/RESTRICTED items and their downstream chains require human decisions. No weekends, resource contention, actual elapsed time, dates, costs or external rights are modeled.

3. Review before action

1. Confirm original source documents, actual completed states, owner permissions, rights and correct task durations. 2. Fix missing or cyclic dependencies, especially tasks with zero float or many downstream dependents. 3. Estimate available staff, business days, realistic buffer, cash and customer approval separately before making a delivery commitment. 4. Record changes to the planning assumptions and get appropriate human review before acting. 5. Review private exports before any sharing; counts-only AI JSON deliberately excludes task descriptions, IDs and source references. NEVER automatically start client work, bill, publish, sign off or accept a deadline on this analysis alone.
