# WIT Experimental Tool Collection

Version 3.5-public-draft.1 · 37 browser applications · fictional-data demonstrations only.

## Start here
Extract the complete ZIP, keep relative files together, and open index.html in a browser that permits local HTML/JavaScript. Every tool is a prototype. Use the supplied fictional examples. Do not enter real personal, employer, customer, financial, tax, security or confidential records. Some tools require FAKE-prefixed IDs by design; do not weaken that restriction to force real data through.

Public source does not make a user's inputs or exports public. PRIVATE labels on reports and AI data contracts are intentional. Review and sanitize any output before sharing it anywhere. No tool sends a message, charges a customer, signs an agreement, validates legal rights, authenticates evidence, or grants permission to act. A clean result means only the tool's declared checks did not flag the supplied toy data.

## What is and is not verified
The shared CSV parser uses the previously reviewed malformed-bare-quote rejection fix. Tools 9–11 reuse the exact corrected 0.1.1-draft.1 HTML from their existing families, rather than creating duplicate inventions. See VALIDATION.md for actual checks on this collection. Prior in-memory checks are historical evidence, not a new all-suite run. Independent real-browser, extracted-file, desktop/mobile, outside-user, real-customer and commercial-demand acceptance remain unverified. Do not infer production readiness from code tests or the ability to download a ZIP.

The remaining applications are experimental source for exploration and improvement, not operational instructions or legal, tax, financial, medical, physical-security, employment or safety advice. Dates, rates and identifiers are illustrative. Independently validate assumptions before considering real-world use.

## Continuation and contribution
See TOOL_CROSSWALK.json for stable entrypoints and existing-family overlap. Do not count versions or bundles as new unique tools. Reproduce a defect with fictional input; record expected versus observed output; identify exact collection version and file hash; review source and output for privacy; then submit through the current WIT contribution process. Do not publish raw reports or private input files.

## Rights and provenance
Read LICENSE_NOTICE.md. Only explicitly scoped MIT-covered portions have that existing grant; the rest is source-available without a new blanket reuse license. Examples are invented; no customer or employer data belongs here. Test scripts use external development dependencies; nothing installs them automatically. Historical internal logs and release planning narration are deliberately omitted; the private source archive remains preserved.
